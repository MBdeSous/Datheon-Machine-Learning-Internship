# Datheon Machine Learning & Data Science Internship

This repository contains machine learning projects completed as part of the Datheon Machine Learning & Data Science Internship.

Each project includes a Jupyter Notebook, supporting dataset, methodology, model evaluation, and documentation.

## Projects

### Task 1 — Iris Flower Classification

A multi-class classification project comparing Logistic Regression and Decision Tree models using the Iris dataset.

Both models achieved 93.3% test accuracy.

[View Task 1](Task-1-Iris-Classification/README.md)

### Task 2 — California Housing Price Prediction

A regression project comparing Ordinary Least Squares, Ridge, and Lasso models using the California Housing dataset.

The project includes exploratory data analysis, feature engineering, preprocessing pipelines, hyperparameter tuning, and residual analysis.

OLS achieved the lowest test RMSE of approximately $69,048.

[View Task 2](Task-2-Housing-Price-Prediction/README.md)

## Technologies

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, and Jupyter Notebook.

## Getting Started

Clone the repository and install the dependencies:

```bash
pip install -r requirements.txt
```

Open the relevant project folder and run its Jupyter Notebook.

## Project Structure

Each task is organized into its own folder with a notebook, dataset, and README documentation.

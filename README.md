# Datheon Machine Learning & Data Science Internship

This repository contains machine learning projects completed as part of the Datheon Machine Learning & Data Science Internship.

Each task is organized into a separate folder containing the implementation, dataset, documentation, and results.

## Projects

### Task 1 — Iris Flower Classification

Implementation and comparison of Logistic Regression and Decision Tree models using the Iris dataset.

Both models achieved 93.3% accuracy on the test dataset.

See [Task 1](Task-1-Iris-Classification/README.md) for the project documentation.
